# Reflection



Throughout this project, I used three **AI tools to support different stages of development:** ChatGPT, GitHub Copilot in Visual Studio Code, and Cursor AI. 

ChatGPT was primarily used for architecture discussions, implementation planning, prompt refinement, reviewing AI-generated code, debugging assistance, analysing implementation alternatives, identifying potential edge cases, and refining solutions after testing. 

GitHub Copilot was my primary coding assistant for generating code suggestions and accelerating implementation inside Visual Studio Code. 

After reaching the available GitHub Copilot usage limit, I continued using Cursor AI for the same development tasks, allowing me to maintain the same workflow throughout the remainder of the project.



One of the **most valuable ways AI helped** was during the implementation of the filtering functionality. Through discussions with ChatGPT, I recognized that search, status, and priority filtering could be designed together as a consistent backend solution rather than as separate features. This encouraged me to consider the overall API design before implementation and compare different approaches before writing code. GitHub Copilot and later Cursor AI then helped speed up implementation by generating code suggestions, allowing me to focus more on reviewing, testing, and refining the generated solutions.



There were also **occasions where AI slowed development** because its initial suggestions did not fully match the project requirements. Early in the project, I initially believed that the search functionality could remain entirely on the frontend. After reviewing the architecture and discussing implementation alternatives, I concluded that backend search would provide a more consistent and scalable solution. Some early prompts also focused only on implementing search and did not include the status and priority filtering requirements. In another case, a debounce mechanism was suggested for the search functionality, but after testing I determined that it added unnecessary complexity for a small learning project. These situations required additional review, prompt refinement, and testing before arriving at solutions that better matched the project scope.



One example where my own review changed the final outcome was expanding the filtering implementation beyond the original search requirement to include status and priority filtering as part of the backend API. I also chose to remove the debounce functionality after testing because the simpler implementation was a better fit for the project requirements. This project reinforced that AI was a valuable development assistant rather than a replacement for engineering judgement. By consistently reviewing, testing, and refining suggestions generated by ChatGPT, GitHub Copilot, and Cursor AI, I was able to produce an implementation that met the project requirements while strengthening my understanding of the technologies and design decisions involved.
