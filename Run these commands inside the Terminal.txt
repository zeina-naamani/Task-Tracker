Run these commands inside the Terminal in the current Task-Tracker folder to check if the application is working:
deactivate
Remove-Item -Recurse -Force .venv
py -3.13 -m venv .venv

First write thus to open the (.venv):
.\.venv\Scripts\Activate.ps1


python -m pip install -r requirements.txt

Then run this to start the link:
python -m uvicorn app.main:app --reload --port 8000

Virtual environments should generally be recreated after moving or renaming a project folder, because they store absolute paths.
